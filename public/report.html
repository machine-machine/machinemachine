Conversation Archiving — Should We Store All Conversations as Files?

Answer: Yes, but structured, not raw.

✅ Do this

  • Auto-export sessions to JSONL on session end
  • Store in archives/conversations/YYYY-MM/
  • Auto-ingest into Qdrant with session metadata
  • Index by agent, user, topic, date
  • Use as RAG corpus for "what did X say about Y"

⚠️ Watch out for

  • Storage growth (compress + deduplicate)
  • Privacy (GDPR for client conversations)
  • Signal/noise ratio (use quality filter)
  • Index staleness (incremental ingest only)

🔴 Critical Gaps (Block Scale)

1. No Org-Level Memory

Every agent is a silo. There's no shared knowledge graph that persists decisions, lessons learned, and organisational knowledge across the fleet. When a new agent spawns, it starts from near-zero.

→ Build org_memory Qdrant collection + ingest pipeline + shared read access for all agents

2. No Conversation Corpus

Every conversation is ephemeral unless an agent manually writes to memory. Thousands of valuable exchanges are lost. No queryable history for "what did we decide about X" across sessions.

→ OpenClaw session export hook → JSONL archive → nightly Qdrant ingest

3. Playbook Not Ingested Fleet-Wide

Fleet Playbook v0.2 exists and is high quality. But most agents don't have it in their active context. The RUNCARD is defined but not verified deployed to all agents.

→ agentx fleet-inject-hook run across all agents, verify RUNCARD presence

4. No Capability Registry

No live API to query "which agent can handle task X". Orchestration is hardcoded. Can't auto-select best agent for a given task type.

→ Build AgentCapabilityRegistry (extends fleet heartbeat with skill inventory)

🟡 Important Gaps (Limit Quality)

5. Role System is Ad-Hoc

Labels (orchestrator/researcher/builder/generalist) exist but lack AIEOS-standard role definitions: accountabilities, domains, policies, authority boundaries. No circle structure.

→ Complete 4 open AIEOS entity definition cards in Dark Factory backlog

6. Dark Factory Loop Not Closed

Everything goes into Qdrant. Low-quality, transient, or duplicate information pollutes the semantic index. Over time this degrades search quality.

→ Add user memory namespace to memory.sh store/search
